# 기술 백과사전 엔진 — 상태

**엔진은 실행 사이에 기억이 없다.** 다음 사이클이 이어받을 것은 이 파일뿐이다.

## 지금 쓰는 중

**직전 사이클에서 `금융권은 왜 Java 인가`(`java-in-finance`)를 끝냈다** — 절 5 · 표 3 ·
실습 3 · 지뢰 6 · 근거 5. **첫 `domain`(도메인 상식) 문서이고, 처음으로 웹 검색을 써서
제도 근거를 1차 자료로 받쳤다**(금융위 보도자료 2건 · 국가법령정보센터 2건).
전체: 문서 5개(전부 done) · 절 27 · 실습 15 · **오류 0 · 경고 0.**

**다음 사이클 = QUEUE 맨 위 `GPIO 레지스터`(`gpio-register`)** — 사다리 3순위(신규).
`atmega128` 이 "DDR/PORT/PIN 이라는 발상 자체"라며 넘긴 자리다. **칩 하나가 아니라
개념 하나를 다루는 문서**라 축이 다르다 — AVR 의 DDRx/PORTx/PINx, STM32 의
MODER/ODR/IDR/BSRR, ESP32 의 GPIO 매트릭스를 **같은 표에 나란히 놓는 것**이 알맹이다.
`compare` 테이블 하나가 이 문서의 중심이 되고, 그게 있어야 `atmega128` 에서 배운 것이
다음 칩으로 옮겨진다(수요는 ARM 쪽이 훨씬 크다).

**쓸 때 주의** — 세 칩의 레지스터 이름과 동작을 **각 벤더 레퍼런스 매뉴얼로 확인**한다.
기억으로 적으면 반드시 틀리고, 이 문서는 틀리면 그대로 남의 회로에 꽂힌다.
확인 못 한 칩은 표에서 빼는 편이 낫다(PROMPT.md 5단계).

## 배운 것

- **웹 검색은 제도·표준 문서에서 값을 한다.** 이번에 `WebSearch`+`WebFetch` 로 금융위
  보도자료의 **정확한 제목·날짜**를 확인하고 인용했다(2024-08-13 망분리 개선 로드맵,
  2026-04-20 내부 업무망 SaaS 예외 시행). 반대로 `law.go.kr`·`egovframe.go.kr` 은
  본문이 자바스크립트라 조문 텍스트를 못 뽑았다 — **URL 은 근거로 걸되 조문 문구를
  단정하지 않고**, 조문 번호는 개정될 수 있다는 단서를 `open_questions` 에 남겼다.
- **alias 는 자원이다.** `Java` 를 `java-in-finance` 가 가져가면 앞으로 쓸 언어 문서가
  관계 화면에 못 걸린다. 그래서 **market 을 비우고** 숫자만 본문에 인용했다.
  **문서 제목이 낱말 그 자체가 아닐 때는 alias 를 먼저 확인한다.**
- **`market` 이 있는 문서는 동반 기술이 목차를 정해 준다**(Python 의 AWS·Docker·K8s).
  숫자를 표에 박아 두고 끝내지 말고 본문이 그 숫자를 다시 인용하게 쓴다.
- **낱말이 공고에 안 걸리면 그 낱말이 전제되는 문장을 찾는다.** `풀업` 0건 →
  `I2C`·`회로도 독해`. `UART|시리얼|Serial` 339건, 파이썬 선택 문장 997건,
  금융 계열(`망분리|전문|계정계|금융권`) 1,556건.
- **표준·벤치마크 숫자는 조심해서 쓴다.** 유료 표준(IEC 60062, TIA/EIA-485)은 링크를
  지어내지 않고 사정을 적는다. 워크로드 의존 수치(3.11 성능)는 배수를 적지 않는다.
- **숫자 표는 계산해서 넣는다**(UART 의 UBRR 오차표).
- **한 문서가 다음 큐를 만든다.** 끊긴 링크로 큐에 오른 것: `i2c`·`ohms-law`(풀업),
  `interrupt`·`rs485`(UART), `gil`·`asyncio`(Python), `java`(금융 Java).
