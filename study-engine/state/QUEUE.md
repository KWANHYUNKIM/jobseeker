# 대기열 — 쓸 낱말

`validate.py --gaps` 의 사다리 3순위가 이 파일의 "대기" 표 **맨 위 한 줄**을 읽는다.
표의 첫 열(낱말)만 기계가 읽는다 — 나머지 열은 사람과 다음 사이클을 위한 근거다.

> ⚠️ 이 문서를 스크립트로 고칠 때 `s.index("## 대기")` 로 자르지 말 것.
> 위 문장에 같은 글자가 있어 인트로 한가운데를 잘라 먹는다. `"\n## 대기"`(줄 시작)로 찾는다.

큐에 올릴 자격은 셋 중 하나다 (PROMPT.md 2⁗단계).
**(a) 수요가 큰데 문서가 없다** / **(b) 이미 쓴 문서가 계속 가리킨다(끊긴 `related`)** /
**(c) 공고·블로그에는 나오는데 어디에도 설명이 없는 말.**

|---|---|---|---|
| 데이터 품질 검증 | `data-quality` | **이 백과사전이 데이터 쪽 문서마다 "조용히 어긋난다"고 경고하고 대응책을 안 준 자리다** — `cdc`(스키마 변경이 파이프라인을 깨뜨린다) · `olap`(원본과 어긋나는지 확인하지 않는다) · `table-format`(정리 안 하면 쌓인다) · `outbox`(미발행이 조용히 쌓인다). **좁은 기준으로 541건(모집중 284)**: `데이터 파이프라인을 직접 설계·운영해 본 경험 (배치/스트림 처리, 멱등성 보장, 백필, 데이터 품질 검증 등)`(웨이커 — **이 문서가 다룰 것이 그 괄호 안에 다 있다**), `데이터 품질 관리(Clean Data) 체계를 설계하여 시스템 전반의 정합성을 확보`(고래사), `데이터 품질 관리 체계 직접 설계 또는 개선 경험`(넛지헬스케어), `Establish data governance, compliance, and access control frameworks to ensure data quality and reliability`(Apple). 축: ①**데이터는 조용히 틀린다** — 테스트가 없으면 대시보드가 틀린 채로 오래 간다 ②**무엇을 검사하나**(건수·널 비율·유일성·범위·**원본 대조**·신선도) ③**언제 검사하나**(적재 전/후 · 파이프라인 단계마다) ④**틀렸을 때 멈추나 지나가나**(막으면 지연, 지나가면 오염 — `dlq` 와 같은 선택) ⑤**소유자가 있어야 고쳐진다**(→ `oncall` 의 액션 아이템) | dbt 문서의 **테스트** 부분과 데이터 검증 도구 문서가 후보. ⚠️ **제품 사용법이 아니라 원리를 쓴다**(`caching`·`grpc` 에서 쓴 방법 — 무엇을 설명하지 않을지 먼저 정한다). **URL 은 `WebSearch` 로 확인** |
| 사가 · 보상 트랜잭션 | `saga` | **`outbox` 가 "별도 문서가 필요하다"고 넘겼고, 공고에서 아웃박스와 거의 항상 함께 나온다.** ⚠️ **근거가 아주 얇다** — `Redux` 계열을 제외하면 **9건(모집중 5)** 이고 그중 둘은 이력서 양식 OCR 잡음이라 **실질 3건**이다(티웨이브 `Outbox, Saga, Event Envelope 등 분산 정합성 패턴을 실제 코드로 작성`, 커넥트웨이브 `saga / cqrs / outbox 패턴`, 일레븐스디 `Transactional Outbox, Spring Modulith, CQRS, SAGA 패턴`). **그 사실을 문서에 밝히고 쓴다**((b) 유형 — 백과사전 안에서 수요가 증명된 자리). 축: ①**여러 서비스에 걸친 작업은 롤백이 없다** — 남의 서비스에 이미 나간 일은 되돌릴 수 없다 ②그래서 **보상 트랜잭션**(취소를 새 작업으로 실행) ③**코레오그래피 vs 오케스트레이션**(이벤트로 이어지나, 지휘자가 있나) ④**보상할 수 없는 단계**(메일 발송·외부 결제 — 순서를 바꿔 뒤로 미룬다) ⑤**중간 상태가 사용자에게 보인다**(→ `slo` 신선도, `cqrs` 최종 일관성) | ⚠️ **표준이 없다**(`cqrs`·`outbox` 와 같은 처리) — **microservices.io(Chris Richardson)** 가 `outbox` 에서 쓴 것과 같은 카탈로그를 갖고 있다. **누가 정리했는지 밝히고**, 원 논문(1987 Sagas)이 있다고 알려져 있으나 **확인하지 못하면 그렇게 적는다** |
