# 사이클 기록

엔진은 이 파일을 읽지 않는다. 사람이 "무엇이 언제 왜 바뀌었나"를 볼 때 쓴다. 새 기록은 위에.

## 2026-09-29 — 사이클: 섞인 매물 4개(사다리 3)

- RTX 4070 SUPER — 섞인 게 아니라 단종 뒤 남은 재고 4건(94만~524만원)이다. `legacy`.
- IronWolf 4TB — '2x4TB·4x4TB 패키지'가 섞였다. `not` 에 패키지를 더해 단품만(331,880원).
- B850 보드·1000W 파워 — 급 단위라 보급~고급 폭이 원래 넓다. validate 의 섞임 검사에서 보드·파워·쿨러·케이스를 뺐다.

## 2026-09-29 — 사진·성능표

- AMD 라데온 페이지의 게임별 FPS(4K·1440p Ultra, 각주 RX-1255~1258 / Max 1440p, 각주 13·15)를 `bench.json` vendor 에
  옮겼다. 탭 4개(9070 XT·9070·9070 GRE·9060 XT 16GB)와 값 묶음의 대응은 aria-labelledby 로 확인 — 9070 XT·9070 은
  4K, GRE·9060 XT 는 1440p 다(글 순서만 보면 1440p 둘을 9070 XT·9070 으로 잘못 붙이기 쉽다). GRE 는 목록에 없어 뺐다.
- 제품 사진 4장(ASUS 2·GALAX 2) — 제조사 og:image 주소와 출처만. MSI·ZOTAC·PNY 는 이번에 사양서(PDF)만 봐서 아직 없다.

## 2026-09-29 — 사이클: 가격 없음 5개(사다리 2)

- RX 7800 XT · Arc B580 — 다나와에 카드 단품 매물이 없다(완제품 안에만 있다). 국내 단품 판매가 끝난 것으로 보고 `legacy`.
- Crucial P3 Plus 1TB — 새 제품은 4TB 만, 1TB 는 중고뿐. `legacy`.
- WD Red Plus 4TB(WD40EFPX, 캐시 256MB) — 해외구매로만 팔린다. 국내 정식 유통은 WD40EFZZ(캐시 128MB) — 다른 모델이라
  이 부품은 `legacy` 로 두고 EFZZ 를 QUEUE 에 올렸다(WD 공식 사양 확인 후 추가).
- DDR5-6000 32GB — 한 장짜리는 없고 '64GB(32Gx2)' 묶음으로만 판다. 크롤러에 `price_query.per`(묶음 ÷ 장수)를 더해
  한 장 값으로 맞췄다 → 738,675원(38건).
