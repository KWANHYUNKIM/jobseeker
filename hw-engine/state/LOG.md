## 2026-09-29 — 확인: DDR5-6000 32GB → 대표 제품(사다리 4a)

- 6000 CL30 은 JEDEC 표준 속도가 아니라 XMP/EXPO 오버클럭 프로필이라 JEDEC 문서(403)로는 원래 확인할 수 없다 — 대표 제품으로 바꿨다.
  G.SKILL Trident Z5 Neo RGB F5-6000J3040G32GX2-TZ5NR 공식 사양: 6000 · 30-40-40-96 · 1.40V · 기본 4800MT/s. 적어 둔 CL30 과 같다.
  **EXPO/XMP 를 안 켜면 4800 으로 돈다**는 것을 specs(default_mts)와 대표 제품 메모에 남겼다.
- G.SKILL 스펙 주소는 숫자 id 가 제품을 정한다(뒤 모델명은 무시) — 16GB 판 id 를 몰라 남겼다. 남은 4a: ram 5.

## 2026-09-29 — 확인: 5700X3D·5600 스펙(사다리 4a)

- amd.com 제품 페이지는 404 지만 **지원(드라이버) 페이지에 같은 사양표**가 있다 — 구형 CPU 는 여기서 읽는다.
  5700X3D 8C/16T · 3.0/4.1GHz · L3 96MB · 105W · 2024-01-08, 5600 6C/12T · 3.5/4.4GHz · L3 32MB · 65W · 2022-04-04. 적어 둔 값과 같다.
  기본 클럭·출시일을 더하고 확인 표시. 4a 남은 것: 메모리 6(JEDEC 403).

## 2026-09-29 — 확인: B850·A620 칩셋 스펙(사다리 4a)

- amd.com AM5 칩셋 사양표가 이번엔 열렸다. **B850 그래픽 슬롯은 PCIe 4.0**(표기상 1x16/2x8) — '5.0 선택' 으로 적어 둔 것을 고쳤다.
  NVMe 1x4 PCIe 5.0 · 레인 36(5.0 4) · CPU 오버클럭. A620 은 그래픽·NVMe 모두 4.0, 레인 32, CPU 오버클럭 불가(EXPO 는 가능).
  둘 다 USB4 는 '보드 선택' 이라 false 대신 그대로 적었다.
- 5700X3D·5600 제품 페이지는 amd.com 에서 404 — 주소를 못 찾아 남겼다(4a 남은 것: cpu 2 · ram 6).

## 2026-09-29 — 사이클: RTX 50 스펙 확인(사다리 4a)
