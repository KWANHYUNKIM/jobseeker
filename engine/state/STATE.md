## 지금 파는 중

*(덮어쓴다. 이어붙이지 않는다.)*

**Zerodha — 34번째 회사.** 사이클 187 까지 프로파일 + 도메인 3개 + 기능 2개
(`contract-notes` · `console-warehouse`). **마지막 남은 도메인은 `로그 저장`** —
자료 정독 완료(`logging-at-zerodha`: 2018년 ELK → **ClickHouse + Vector + Metabase(사내 이름 Loj)**.
Elasticsearch 는 **모든 필드를 색인해 저장량이 원본의 최소 3~4배**, *"긴 기간 집계 질의가 느리다"*.
결과: 같은 **6,500만 행이 22.1GB → 1.13GB(20배)**, 행당 **340바이트 → 17.38바이트**, 전체는
ELK **280억 줄 13TB** → Loj **300억 줄 2.5TB**, 시간당 **$2.67 → $1.14**. **Loki 를 두 번 검토해 두 번 다 버렸고**
cLoki 도 버렸다. ClickHouse 도 그냥 되지 않았다 — **활성 파트 최대치 도달**로 Vector 애그리게이터 도입,
**기본 키는 만든 뒤 바꿀 수 없다**). **두 번째 글은 `scaling-with-common-sense` 계열을 쓴다**(둘 다 정독 완료).
**채우면 Zerodha 를 done 으로 닫고 곧바로 후보 조사 사이클**(큐 1/3).

> **`console-warehouse` 에서 나온 것 — 캐시를 키-값이 아니라 데이터베이스로 만들었다.**
> Redis 를 버린 이유가 *"사용자가 뽑을 수 있는 수십 종류의 리포트에 필터링과 정렬을 구현하는 것이 복잡했을 것"*
> 이다. **답을 미리 정해 두는 캐시로는 질문이 정해지지 않은 데이터를 못 담는다.** 그래서 전용 PostgreSQL 을
> 캐시로 두고 밤마다 굽는다 — *"우리 캐시 DB 는 매일 하루가 끝날 때 **수천만 개의 테이블**을 갖게 된다"*(원문 확인함).
> **미리 정해 둔 답이 아니라 미리 모아 둔 재료**라는 구분이 이 기능의 축이다.

> **⑳ 새 축 후보 — '남의 도구를 거절한 이유가 성능이 아니었다'.** Citus 거절 이유는
> *"모든 샤딩 테이블에 새 참조 ID 컬럼을 추가한다. 수백 개의 질의를 다시 써야 하는 그 길로 가고 싶지 않았다"*
> — **침습성**이다. trivago 가 Federation 을 버린 이유(*"상류가 GraphQL 을 채택하고 스키마를 조율해야 해서"*)와
> **정확히 같은 모양**이다. Allegro 의 FaaS 포기(*"의존성 100%에 적용할 수 없다"*)도 결이 비슷하다.
> **재료가 셋이 됐으니 비교 문서를 쓸 수 있다.**

> **이 회사가 내려놓은 정석 목록** — 정규화 · 자동증가 ID · 외래키 · 남의 샤딩 확장 · 관리형 DB.
> 그리고 **일 단위 파티셔닝은 해 보고 되돌렸다**(삽입은 빨라졌지만 날짜 범위 질의가 느려져서).

### PDF 를 직접 읽는 법 — 사이클 176 에서 뚫었다

WebFetch 가 PDF 를 못 읽는다고 답해도 **응답 끝에 로컬 저장 경로를 알려 준다.** 그 파일에
poppler·pypdf 없이 순수 파이썬으로 접근할 수 있다. Allegro IR 발표자료(4.2MB)에서 실제로
매출·GMV·테이크레이트를 전부 뽑았다.

1. `re.finditer(rb'stream\r?\n', d)` 로 스트림을 찾아 `zlib.decompress` — 실패하는 것은 건너뛴다.
2. `beginbfchar`/`beginbfrange` 가 있는 스트림에서 **ToUnicode CMap** 을 만든다.
3. 본문 스트림(`Tj`/`TJ` 포함)에서 텍스트를 뽑는다. 두 형태가 있다 —
   `<hex>` 형과 **2바이트 코드를 리터럴 문자열 `(...)` 에 담은 형**(팔진 이스케이프를 풀어야 한다).
4. 코드를 CMap 으로 옮긴다.

> ⚠️ **CMap 을 문서 전체에서 하나로 합치면 폰트가 섞여 글자가 밀린다**(TITLE 이 SHSKD 로 나온다).
> 페이지 대부분이 멀쩡하면 그대로 쓰되, **밀린 페이지는 버린다.** 그리고 **자간이 낱글자로
> 벌어져 나오는 경우가 있다**(`A l l e g r o`) — 수치는 붙어 나오므로 읽는 데는 지장이 없다.
