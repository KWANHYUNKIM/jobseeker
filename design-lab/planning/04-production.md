# 4. 제작·검수 — 올리기 전 점검표

판은 `poster/` 로 찍는다(`series`·`balance`). 승인 전에 아래를 하나씩 본다. 실수가 나오면 여기 한 줄 더한다.

## 사실
- [ ] 모든 숫자에 출처가 있다 — 공고 원문(회사·마감일) 또는 통계(기관·기준 시점). 판 아래 한 줄 + 캡션 전체.
- [ ] 공고를 인용하면 **직무가 정말 그 직군인가** 원문을 읽었다(2026-10-01: 'AI 콘텐츠 PD' 를 개발 공고로 쓸 뻔했다).
- [ ] 복지 표현은 원문 그대로 — '사택' 과 '주거지원비' 는 다르다(2026-10-01 실수).
- [ ] 마감된 공고는 '지난 공고(마감일)' 로 적었다.
- [ ] 가정으로 세운 선택지는 판에 '가정' 이라고 적었다.
- [ ] 정규식으로 센 숫자(재택·식사·경력 요건)는 무작위 5건을 원문으로 확인했다.

## 권리
- [ ] 사진: Wikimedia Commons CC/PD(작가·라이선스 판마다) · 회사 공식·제작사 사례(출처 표기, 승인 = 사용 허락 확인) — 개인 SNS 사진 없음.
- [ ] 지도: © OpenStreetMap contributors 표기.
- [ ] 음원: 영상에는 우리 것만. 유행곡은 앱에서 붙인다.

## 형식 (02 기준)
- [ ] 길이: 표 5~8초 · 밸런스 6초 · 밈 10초 이하 · 그 밖 15초 이하.
- [ ] 첫 프레임: 2줄 · 줄당 10자 안팎 · 핵심어 하나 노랑 · 첫 1초에 결론/질문.
- [ ] 위 250px·아래 420px 에 글 없음.
- [ ] 끝 장면이 첫 장면으로 이어진다(마무리 인사 장면 없음).
- [ ] 캡션 첫 줄 = 댓글 질문, 해시태그 5개 이하.
