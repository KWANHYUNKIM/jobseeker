# 이럴 땐 이렇게 — 릴스 지침

[reels-study.md](reels-study.md) · [teardown.md](teardown.md) 에서 근거가 쌓인 것만 올린다. 줄마다 근거 편을 단다.
근거가 한 편뿐이면 '?' — 두 편 이상 같은 결과가 나오면 '?' 를 뗀다. `insta-reels` 루프가 회차마다 고친다.

## 목적별

| 이럴 땐 | 이렇게 | 근거 |
|---|---|---|
| **댓글을 받고 싶다** | 판단할 대상을 하나 둔다 — 악역(막말 면접관), 회색지대 규범(연차 중 연락), 의외의 주장. 홍보·칭찬만 있는 영상은 댓글이 없다 | 면접 후기 · 연차 메모 · 네이버 인터뷰(반례) |
| 댓글을 받고 싶다(정보형) | 1위를 가리고 캡션에서 공개 / "댓글에 ○○ 남기면 원본" / **정체성 도발 퀴즈**('이거 틀리면 개발자 아님' + 쉬워 보이는 함정) — 정답은 고정 댓글로 | 초봉 피라미드(1,121) · 취업지원금(2,615) · 코드 퀴즈(161, 함정 논쟁) |
| **'나도 겪었다' 를 끌어내고 싶다** | 실제 근거(후기 카드·공고 원문)를 화면에 두고 그 상황을 보여 준 뒤, **캡션에서 '당해본 ○○ 댓글로 공유해줘'** 로 부른다 — 댓글이 사연이 된다 | 면접 후기 · 좋소 연차(사연 댓글 9,346♥) |
| 첫 1초에 붙잡고 싶다 | 설명이 필요 없는 장면 한 컷(지옥철 인파, 결과 조회 직전 휴대폰, 빈 식판) + 혼잣말 한 줄 | 출근길 · 해경 · 구내식당 |
| 끝까지 보게 하고 싶다 | 결과를 늦게(합격 발표·S티어·합계), 하나씩 채우기, 말하다 끝내기(마무리 장면 없음) | 해경 · 가계부 · 비빔밥데이 · 티어표 |
| 다시 보게 하고 싶다 | 한 화면에 다 못 읽을 만큼 담긴 표 5~8초, 또는 결말 직전에 끊기 | 연봉 티어표들 · 가계부(합계 쓰다 끝) |
| 저장하게 하고 싶다 | 따라 할 숫자(가계부·실수령표)를 화면에, 캡션에 전체 | 가계부 · 실수령액 |
| 비팔로워에게 퍼지고 싶다 | 개인 이야기보다 **많은 사람이 매일 겪는 장면**(출근·점심·연차·면접) | 출근길 · 구내식당 · 연차 |
| **자기 대입·동료 태그를 원한다** | 딱지를 붙인다 — 직군 이름표(개발자·기획·PM·엔지니어), 회사 등급(좋소·대기업) | 엔지니어 vs PM(태그) · 현대오토에버 고양이(직군) · 좋소 복지 |
| 회사·복지를 보여 줄 때 | **역설 제목**('(선넘는) 좋소 복지', '연봉보다 무서운 복지 감옥') + 번호 목록 + 항목마다 진짜 장면 | 좋소 복지(1.8%) · 복지 감옥 BEST 7(581만) |
| 일반화 반발이 걱정될 때 | 화면 아래 작은 면책 한 줄('모든 ○○을 말하는 게 아닙니다') | 좋소 연차? |
| 노래를 고를 때 | 가사가 상황을 말하는 곡('퇴근', '퇴근하겠습니다', '퇴사할게여') | 출근길 · 회식 · 연봉 위젯 |

## 하지 말 것

| 이럴 땐 | 하지 마라 | 근거 |
|---|---|---|
| 회사·브랜드를 소개할 때 | 잘 만든 인터뷰만 길게(70초+) — 조회는 나와도 대화가 없다 | 네이버 인터뷰(좋아요율 0.2%) |
| 사람이 찍힌 장면 | 얼굴이 알아볼 만하면 항의가 온다 — 가리거나 뒷모습·손만 | 출근길("저 있네요 삭제요청") |
| 의외의 조합을 내세울 때 | 근거 없이 쓰면 '주작' 댓글이 덮는다 — 증거(면허·시각)를 같이 | 한의사 브이로그? |
| 사람을 주인공으로 할 때 | 얼굴이 주인공이면 반응이 외모로 간다(내용 반응 없음) — 우리는 손·화면·물건으로 | 비서 브이로그 · 한의사 |
| 남의 영상이 웃길 때 | 재업로드 + 자막은 원본이 아니다 — 추천에서 빠진다(2026-04 인스타) | 엔지니어 vs PM · strategies S12 |

## 우리(@devjobseeker)에게 옮기면

- 판단할 대상: **공고 원문** — "신입 환영인데 경력 3년", "연봉 2,800 + 야근 당연" 같은 실제 문장을 화면에 고정(회사 이름은 가린다). 
- 실제 근거 고정: 면접 후기 카드처럼 **공고 캡처 카드**를 아래에 두고, 위에서 상황을 보여 준다(출연자 없이 글·그림 캐릭터로 될지 시험).
- 매일 겪는 장면: 출근길·점심·연차 — 우리 데이터(권역별 공고 수·점심 가격·연차 문구)를 얹는다.
- 개발자 퀴즈: '이거 틀리면 개발자 아님' 형식으로 **공고 자격요건에 자주 나오는 기술**(우리 스택 집계)에서 함정 문제 — 정답·해설은 고정 댓글.
- 딱지: '좋소 공고 vs 대기업 공고', '개발자 공고 vs 기획 공고' — 직군·회사 등급 이름표를 화면에.
