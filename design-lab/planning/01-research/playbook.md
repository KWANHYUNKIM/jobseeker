# 이럴 땐 이렇게 — 릴스 지침

[reels-study.md](reels-study.md) · [teardown.md](teardown.md) 에서 근거가 쌓인 것만 올린다. 줄마다 근거 편을 단다.
근거가 한 편뿐이면 '?' — 두 편 이상 같은 결과가 나오면 '?' 를 뗀다. `insta-reels` 루프가 회차마다 고친다.

## 목적별

| 이럴 땐 | 이렇게 | 근거 |
|---|---|---|
| **댓글을 받고 싶다** | 판단할 대상을 하나 둔다 — 악역(막말 면접관), 회색지대 규범(연차 중 연락), 의외의 주장. 홍보·칭찬만 있는 영상은 댓글이 없다 | 면접 후기 · 연차 메모 · 네이버 인터뷰(반례) |
| 댓글을 받고 싶다(정보형) | 1위를 가리고 캡션에서 공개 / "댓글에 ○○ 남기면 원본" / **정체성 도발 퀴즈**('이거 틀리면 개발자 아님' + 쉬워 보이는 함정) — 정답은 고정 댓글로 | 초봉 피라미드(1,121) · 취업지원금(2,615) · 코드 퀴즈(161, 함정 논쟁) |
| **'나도 겪었다' 를 끌어내고 싶다** | 실제 근거(후기 카드·공고 원문)를 화면에 두고 그 상황을 보여 준 뒤, **캡션에서 '당해본 ○○ 댓글로 공유해줘'** 로 부른다 — 댓글이 사연이 된다 | 면접 후기 · 좋소 연차(사연 댓글 9,346♥) |
| 첫 1초에 붙잡고 싶다 | 설명이 필요 없는 장면 한 컷(지옥철 인파, 결과 조회 직전 휴대폰, 빈 식판) + 혼잣말 한 줄 | 출근길 · 해경 · 구내식당 |
| 끝까지 보게 하고 싶다 | 결과를 늦게(합격 발표·S티어·합계), 하나씩 채우기, 말하다 끝내기(마무리 장면 없음) | 해경 · 가계부 · 비빔밥데이 · 티어표 |
| 다시 보게 하고 싶다 | 한 화면에 다 못 읽을 만큼 담긴 표 5~8초, 또는 결말 직전에 끊기 | 연봉 티어표들 · 가계부(합계 쓰다 끝) |
| 저장하게 하고 싶다 | 따라 할 숫자(가계부·실수령표)를 화면에, 캡션에 전체 | 가계부 · 실수령액 |
| 비팔로워에게 퍼지고 싶다 | 개인 이야기보다 **많은 사람이 매일 겪는 장면**(출근·점심·연차·면접) | 출근길 · 구내식당 두 편(642만·1,026만) · 연차 |
| **자기 대입·동료 태그를 원한다** | 딱지를 붙인다 — 직군 이름표(개발자·기획·PM·엔지니어), 회사 등급(좋소·대기업). 개발자면 **'개발자라면 99%' + 매일 겪는 장면 몰아 보기** → 사연(C2)·동료 태그(C13) | 엔지니어 vs PM(태그) · 현대오토에버 고양이(직군) · 좋소 복지 · 개발자 99% 소름(720♥ 말장난·616♥ 사연) |
| 회사·복지를 보여 줄 때 | **역설 제목**('(선넘는) 좋소 복지', '연봉보다 무서운 복지 감옥') + 번호 목록 + 항목마다 진짜 장면 | 좋소 복지(1.8%) · 복지 감옥 BEST 7(581만) |
| 일반화 반발이 걱정될 때 | 화면 아래 작은 면책 한 줄('모든 ○○을 말하는 게 아닙니다') | 좋소 연차? |
| **출연자 없이 만들고 싶다** | 사무실 물건(의자·모니터·컵)에 **종이 한 장 속마음**, 2~3초씩 자리를 옮긴다 — 또는 AI·그림 **캐릭터**가 연기. 얼굴이 없으니 반응이 내용으로 간다 | 연차 메모 · 우리 회사 풍경(587만) · 《인턴》 AI · 퇴사 수달(326만) |
| 숫자로 끝까지 보게 하고 싶다 | 큰 숫자 하나(월급 입장)에서 **하나씩 빠져나가거나 채워지는 목록** → 마지막 합계·잔액(0원) | 가계부 · 월급 퇴장 · 카드값 완납 |
| 정보가 길다 | 영상은 12초 예고('캡션에 써둘 테니 꼭 저장' · '캡션에서 확인하세요'), **본문은 캡션 체크리스트**, 캡션 첫 줄 '저장 —'. 댓글로 오는 '제 경우는요?' 질문을 다음 편으로 | 이상한 회사 거르는 법 · 면접 팁(growreader) · 이직 사유 12개(281만) · 가계부 |
| 좋아요를 받고 싶다 | 화면 아래 작은 한 줄로 '○○한 사람 ❤ 눌러주세요' — 자기 해당 여부를 누르게 | 월급 퇴장(1.9%)? |
| **돈 표를 쓸 때** | 정지 표는 다시 보기로 조회는 나오지만 좋아요가 거의 없고 댓글은 '틀렸다'·'세전? 세후?' 가 된다. **기준(신입·연차·세전/세후)·출처를 제목 옆에**, 사람들이 원하는 비교(평균 말고 신입)로, 반응을 부를 질문 한 줄을 따로 | 직업 TOP30(0.05%) · 중견기업 티어(0.06%, '신입 연봉으로 비교해라' 173♥) · 월급 상위 %(0.03%, '세전? 세후?' 답글 15) · web-learning 다시 보기 |
| 다음 편 요청을 쌓고 싶다 | 딱지(MBTI·직군) 중 **1위만 공개** + 이유 단어를 하나씩 터뜨린다 — 댓글이 '○○ 는요?' 로 다음 편을 요청 | 공무원 MBTI 1위('INTP는요?') · 개발자 99%? |
| 해외 비팔로워까지 | 말 없이 통하는 장면(음식·물건) + **한·영 이름표**, 캡션에 위치·가격 키워드 | 구내식당 파트41(1,026만·외국어 댓글) · 공식 키워드 팁 |
| 시리즈로 이어 가고 싶다 | 같은 틀에 번호만 바꾼다('파트41') — 한 편이 터지면 앞 편까지 본다(?) | 구내식당 파트41 · 365_bab.zip |
| 노래를 고를 때 | 가사가 상황을 말하는 곡('퇴근', '퇴근하겠습니다', '퇴사할게여', '칼퇴근') | 출근길 · 회식 · 연봉 위젯 · 칼퇴근(808만, 댓글 4,146 태그) · 공식 '오디오 페이지' 신호 |
| **태그·보내기를 원한다** | **따라 말하게 되는 한 줄**(가사·주문 '하루만 버티자')을 한 줄씩 늘려 가며 자막으로 — 친구에게 '너 얘기' 로 보낸다 | 칼퇴근(3.0%) · 버티자(2.5%, 2,711 태그) · 공식 보내기 신호 |

## 하지 말 것

| 이럴 땐 | 하지 마라 | 근거 |
|---|---|---|
| 회사·브랜드를 소개할 때 | 잘 만든 인터뷰만 길게(70초+) — 조회는 나와도 대화가 없다 | 네이버 인터뷰(좋아요율 0.2%) |
| 사람이 찍힌 장면 | 얼굴이 알아볼 만하면 항의가 온다 — 가리거나 뒷모습·손만 | 출근길("저 있네요 삭제요청") |
| 의외의 조합을 내세울 때 | 근거 없이 쓰면 '주작' 댓글이 덮는다 — 증거(면허·시각)를 같이 | 한의사 브이로그? |
| 사람을 주인공으로 할 때 | 얼굴이 주인공이면 반응이 외모로 간다(내용 반응 없음) — 우리는 손·화면·물건으로 | 비서 브이로그 · 한의사 |
| 남의 영상이 웃길 때 | 재업로드 + 자막은 원본이 아니다 — 추천에서 빠진다(2026-04 인스타) | 엔지니어 vs PM · strategies S12 |
| 성과를 볼 때 | 댓글 수로 재지 마라 — '궁금해요' 키워드 미끼는 댓글만 부풀린다. 도달 대비 좋아요·보내기·시청 시간(공식 신호)으로 본다 | 얼집교사 월급공개(댓글 1,844 · 좋아요율 0.09%) · web-learning Mosseri |

## 우리(@devjobseeker)에게 옮기면

- 판단할 대상: **공고 원문** — "신입 환영인데 경력 3년", "연봉 2,800 + 야근 당연" 같은 실제 문장을 화면에 고정(회사 이름은 가린다). 
- 실제 근거 고정: 면접 후기 카드처럼 **공고 캡처 카드**를 아래에 두고, 위에서 상황을 보여 준다(출연자 없이 글·그림 캐릭터로 될지 시험).
- 매일 겪는 장면: 출근길·점심·연차 — 우리 데이터(권역별 공고 수·점심 가격·연차 문구)를 얹는다.
- 개발자 퀴즈: '이거 틀리면 개발자 아님' 형식으로 **공고 자격요건에 자주 나오는 기술**(우리 스택 집계)에서 함정 문제 — 정답·해설은 고정 댓글.
- 딱지: '좋소 공고 vs 대기업 공고', '개발자 공고 vs 기획 공고' — 직군·회사 등급 이름표를 화면에.
- 출연자 없음: **공고 문장을 의자 위 종이에** — '신입 환영(경력 3년)', '연봉 회사 내규' 를 붙인 빈 사무실. 또는 캐릭터 한 마리가 공고를 읽는 장면.
- 숫자 결말: '연봉 3,200 입장 → 4대보험·소득세·월세·교통비 퇴장 → 남는 돈' — 우리 실수령 계산을 하나씩 빼는 형식.
- 돈 표: 평균 연봉 표 대신 **우리 신입 초봉(회사별 공고 하한)** — 댓글이 직접 요구한 비교. 제목 옆에 '공고 기준·신입' 을 박고 마지막에 '당신 회사는 몇 티어?' 질문.
- 태그용: 개발자가 따라 말할 한 줄('오늘은 배포 안 해요', '제 PC 에선 되는데요')을 한 줄씩 쌓는 자막 릴스 — 화면은 우리 그림, 소리는 유행 음원.
- 다음 편 요청: '야근 제일 많은 직군 1위' 처럼 우리 공고 데이터로 1위만 공개 → '백엔드는요?' 댓글을 받아 다음 편.
