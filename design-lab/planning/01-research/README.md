## 가설 (확인할 것)

- H1 우리 데이터 표(신입 연봉 적은 회사 티어 등)도 R2 처럼 터지나 → 03 의 1순위 일감으로 검증.
- H2 6초 밸런스 게임이 12초판보다 건너뛰기 비율이 낮은가 → 같은 주제 두 길이로 올려 비교.
- H3 첫 프레임에 숫자(연봉)가 있으면 건너뛰기가 준다.
- H4 개발자 한정(좁은 주제)보다 직장인 전체(넓은 주제)가 추천이 넓다 — 그러나 파이프라인 전환은 좁은 쪽이 낫다. 섞는 비율을 찾는다.
