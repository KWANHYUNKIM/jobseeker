여기는 그 앞과 뒤, 즉 **무엇을, 왜, 어떤 모양으로 만들고, 올린 뒤 무엇을 배웠는지**를 적는다.

```
0 목표·지표 → 1 조사 → 2 형식(릴스 규격·디자인) → 3 내용(무엇을) → 4 제작·검수 → 5 발행 → 6 측정·회고 ─┐
              ↑                                                                                    │
              └──────────────────────── 회고에서 나온 질문이 다음 조사가 된다 ─────────────────────────┘
```
