파이프라인

한 회차가 지나가는 단계와 이번 회차의 사이트별 수집량.

    이번 회차 사이트별 수집

    데이터 품질

    직전 회차 기준 — 건수와 필드 채움률.

    회차 추이

    최근 10회차.

    시각수집모집중중복채움률

    이벤트 로그

    최근 80건, 새것이 위.

    뷰어 데이터 빌더

    뷰어가 읽는 파일의 나이. 6시간 넘으면 빨갛게.

    반복 작업

    launchd · 크롤 단계 · /loop 엔진 — 산출물 나이로 판정.

    —
    상태종류이름주기마지막실행

    /loop 엔진은 세션이 닫히면 멈춘다 — 다시 시작할 때는 python -m automation.loops prompt <키> 의 출력을 /loop 에 준다.
