# 관리자 — 이력서 자동화 (AX)

**비공개 로컬 도구.** 공개 JD 뷰어와 완전히 분리되어 있으며, **오직 이 맥(`127.0.0.1`)에서만** 접속됩니다.
ngrok·공개 서빙 경로에서는 절대 참조하지 않으므로 인터넷에 노출되지 않습니다.

## 실행

```bash
cd catch_capture
.venv/bin/python -m admin.server      # 또는: ./admin/run.sh
```

접속: **http://127.0.0.1:8910**  (포트 변경: `ADMIN_PORT=9000 ...`)

## 기능

1. **사실 프로필** — 경력·프로젝트·스킬·학력·자격증·링크를 구조화 저장.
   모든 AI 생성/분석의 **유일한 근거**입니다. 사실만 입력하세요.
2. **자동 적합도 분석** (탭) — 사실 프로필로 **전체 공고를 규칙 기반 자동 점수화·랭킹**(즉시·무료).
   - tech_stack·자격요건·우대·주요업무에서 기술을 추출해 매칭/부족 스킬 산출, 공고별 **도메인 분류**.
   - 최소점수·도메인·키워드 필터. 상위 공고는 'AI 정밀분석'으로 심화.
3. **JD 검색·생성** — 크롤된 공고를 검색 → 공고 선택 후:
   - **적합도 분석(AI)**: 내 프로필 vs JD → 점수·충족 항목·갭·부족 스킬
   - **이력서/자기소개서 생성(AI)**: 프로필 사실만으로 초안 작성.
     프로필에 근거 없는 항목은 본문에 지어내지 않고 **'갭'으로 표시**(환각 방지).
4. **지원 폼 수집 + 문항별 답안** — 사이트마다 다른 지원 폼에 대응.
   - 지원 페이지를 **직접 로그인해서** 열고, 설치한 **북마클릿**을 누르면 그 페이지의
     자소서 문항·글자수가 클립보드에 복사됨(페이지에서 네트워크 호출 없음 = 계정 위험 최소).
   - 관리자 '지원 폼' 탭에 붙여넣기 → AI가 **문항별로 글자수 제한 맞춰 사실기반 답안** 생성.
   - **제출은 직접** 한다(자동 제출 없음 — ToS·계정정지·비가역 행위 방지).
5. **재공고 추적** — 마감돼도 같은 회사·직무가 다시 열리면 활용.
   - 관심 공고를 '재공고 추적'으로 등록하면 **JD를 스냅샷으로 저장**(마감돼도 자격요건 보관).
   - '지금 떴나 확인' / '전체 재등장 확인' → 현재 열려있는 매칭 공고를 찾아줌.
   - 년도별로 정리됨.
6. **지원 현황** — 공고별 상태(관심/작성중/지원완료/서류합격/면접/최종합격/불합격) 관리.

## 지원 자동화 범위 (의도적 한계)

- 하는 것: 채널/문항 파악 + 문항 맞춤 답안 생성(사실기반) + 현황 추적.
- **안 하는 것: 자동 로그인·자동 제출.** 자동 제출은 ToS 위반·봇탐지·계정정지 위험이 크고,
  "내 이름으로 회사에 지원서가 날아가는" 비가역 외부 행위라 사람이 검토 후 직접 제출한다.

## AI 키

이력서 생성·적합도 분석은 Anthropic API를 씁니다(모델 `claude-opus-4-8`).
**설정 탭**에서 키를 입력하면 `admin/.secrets.json`(git 제외, 권한 600)에 저장됩니다.
환경변수 `ANTHROPIC_API_KEY`가 있으면 그것을 우선 사용합니다.

## 데이터 위치 (모두 git 제외)

- `admin/data/profile.json` — 사실 프로필
- `admin/data/applications.json` — 지원 현황
- `admin/data/resumes/*.json` — 생성된 이력서 보관
- `admin/.secrets.json` — API 키

## 보안 설계

- 서버는 `127.0.0.1`에 **고정 바인딩**(0.0.0.0 옵션 없음).
- 관리자 UI는 공개 번들(jd-viewer)과 분리된 자체 정적 파일 — 공개 사이트로 새지 않음.
- 개인 데이터·키는 `.gitignore`로 추적 제외.
