# 카드 표지 — 한눈에 걸리는 첫 장

표지의 일은 하나다: 피드에서 **멈추게 하고 → 넘기게 하고 → 저장·공유하게** 한다. 예쁘게가 아니다.
근거는 `references/evidence.md`, 유형은 `references/archetypes.md`.

## 만들기 전에 (순서대로)

1. **주인공 하나를 고른다** — 회사(로고) · 사실 숫자 하나 · 질문 · 표 · 비교. 풍경은 주인공이 될 수 없다.
2. **유형을 고른다** — `archetypes.md` 의 A~F 중 하나. 이번 회차에 시험할 것은 `python -m agent knobs` 가 정한다.
3. **2번째 장을 먼저 정한다** — 표지가 약속한 것을 거기서 바로 갚는다. 2번째 장도 표지처럼(다시 보여질 수 있다).
4. **원고를 쓰고 검사한다** — `cd design-lab && python -m agent eval <코너>`. 실패가 있으면 찍지 않는다.
5. 찍은 뒤 **그림을 직접 열어** 1초만 보고 무엇인지 말할 수 있는지 본다(한눈 시험).

## 늘 지킬 것 (검사가 본다 — `design-lab/evals/checks.py`)

| 검사 | 규칙 |
|---|---|
| `week-pill` | 회차 알약(`10월 4주차`)은 늘 같은 자리 |
| `title-two-lines` | 제목 두 줄, 한 줄 14자 이하 |
| `focal-max-3` | 초점은 셋 이하 |
| `known-name` | 표지에 아는 이름 — 회사 로고나 회사 이름 |
| `number-is-fact` | 표지 숫자는 DB 의 사실(건·곳·%). `VOL.01` 같은 장식 숫자 금지 |
| `second-pays` | 표지가 물으면 2번째 장이 바로 답한다 |

검사가 못 보는 것: 계절은 바탕 풍경이 아니라 강조색·소재로 · 과장·낚시 금지(신뢰가 깎이면 저장·공유가 준다) ·
검정 바탕을 기본으로 쓰지 않는다.

## 멈춤 신호 — 이 생각이 들면 멈추고 위로 돌아간다

- "가을 느낌이 좋으니 사진을 크게" → 사진은 바탕, 주인공은 회사·숫자다.
- "숫자가 없으니 VOL.01 이라도" → 장식 숫자는 약속을 못 갚는다. 숫자를 빼라.
- "로고가 없는 회사가 많으니 이름은 빼자" → 가장 큰 회사 하나의 이름만이라도 표지에.
- "검사는 나중에" → 검사에 실패한 원고는 찍지 않는다.
- "회사 이름을 제목에 다 넣자" → 이름은 로고·부제로. 제목 한 줄은 14자를 넘지 않는다(2026-10-19 시험에서
  스킬을 읽은 에이전트도 '한국수력원자력·SK AX' 15자로 넘겼다).
- "이건 잘 나올 것 같다" → 판정·점수는 사람(8780 `/design`)만 매긴다. 예측은 적되 점수를 매기지 않는다.

## 핑계와 반박

| 핑계 | 반박 |
|---|---|
| 사용자가 가을 느낌을 좋아했다 | 좋아한 건 색과 계절감이다. 강조색·소재로 남기고 주인공 자리는 비켜라 |
| 정보가 많아야 저장한다 | 저장은 넘긴 다음 일이다. 표지는 멈추게만 — 정보는 2~20번째 장에 |
| 질문형은 다 낚시다 | 2번째 장이 바로 답하면 낚시가 아니라 약속이다(`second-pays`) |
| 다른 계정을 그대로 베끼면 된다 | 형식(배치·장치)만 빌린다. 글·그림·로고 이미지는 우리 것과 원 권리자 것만 |
