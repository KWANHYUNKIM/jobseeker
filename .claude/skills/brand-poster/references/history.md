# 판 만들기 — 경위와 결과

왜 절차가 이렇게 됐나(v0→v3 사용자 판정)와 지금까지 만든 판. 새 규칙의 근거는 여기서 찾는다. 원래 `design-lab/brand-poster 스킬` 였던 것을 절 번호 그대로 옮겼다.

## 0. 이 절차가 이렇게 된 이유 (2026-09-15, 6개 회사로 네 번 고쳤다)

| 판 | 무엇을 했나 | 사용자 판정 |
|---|---|---|
| v0 | 회사 색 + 제품 모양 장식 SVG + 수치 카드 | "너무 AI 스럽다" |
| v1 | 웹 CSS 에서 색·글꼴을 뽑아 레퍼런스 틀에 칠함 / 웹·앱 화면에서 포인트 | "포인트가 없다, 이전과 똑같다" |
| v2 | 실제 전용 서체 조사 + 공식 자료 픽셀 색 + 실제 브랜드 이미지 | 롯데카드·배민만 **크게 좋아짐**, 나머지 넷은 "크게 달라진 게 없다" |
| v3 | 사람들이 그 회사로 기억하는 **대표 물건(시그니처) 하나**를 판의 중심에 | "**훨씬 더 좋아졌다**" |

배운 것:

1. **색·글꼴·웹 UI 는 회사를 구별하지 못한다.** 흰 바탕 + Pretendard + 강조색 하나는 거의 모든 회사다. 웹 버튼 색은 브랜드 색이 아니다(롯데카드 보라 ≠ LOCA BI 웜그레이).
2. **서체·색을 '진짜'로 바꿔도 뼈대가 웹 UI 면 인상은 안 바뀐다.** (토스·컬리·카카오뱅크·무신사 v2)
3. **판을 바꾸는 건 대표 물건이다.** 롯데카드 = LOCA 네 창문 + 동판화 맨해튼 지도, 배민 = '송파구에서 일을 더 잘하는 11가지 방법' 포스터 + 사명 붓글씨. 이게 판의 얼굴이 된 회사만 좋아졌다.
4. **흉내보다 원본.** 손으로 그린 지도 SVG·서체로 흉내 낸 붓글씨보다 회사가 만든 원본 이미지를 넣은 판이 낫다.

## 2026-10-19 — 규칙 검사(`python -m evals.brand`)를 처음 돌린 결과

- 데이터 규칙은 고쳤다: 보조 포인트가 8~11개이던 여섯 곳(롯데카드·무신사·우아한형제들·카카오뱅크·컬리·토스)을
  둘로 줄이고 나머지는 `points_set_aside` 로(시그니처 중복 / 서체·색·글자 규칙 / 빼기 — 원문 그대로 보관).
  탈락 후보는 예전 이름(`alternatives_considered`, `why_not_main`)에 이미 있었다 — 표준 이름으로 옮겼다.
- **매체를 실제 렌더를 보고 적었더니(`medium.observed: true`) 24곳 중 18곳이 세 무리로 겹쳤다.**
  flat/full/print 9곳 · photo/full/print 5곳 · paper/full/print 4곳. 공통 원인은 `text_load: full` —
  시그니처는 머리나 귀퉁이에만 있고 판의 대부분은 공고 전문 문서다(당근 하트는 귀퉁이 장식, 네이버·쏘카·오늘의집은
  '사진 머리를 얹은 문서'). 안 겹치는 다섯 곳(빗썸·CJ ENM·포티투닷·미리디·토스플레이스)은 넷이 one-line 이거나
  매체 자체가 다르다.
- 다음 판의 방향: 2-1절 그대로 — 표지(one-line/one-word, 시그니처가 판 전체)와 본문(전문)을 나눈다.
  observed 매체는 '지금 이렇다' 이지 '이래야 한다' 가 아니다 — 다시 만들 때 시그니처에서 새로 고른다.
