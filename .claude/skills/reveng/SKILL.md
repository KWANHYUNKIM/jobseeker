# 역설계 엔진 사이클

**한 번 호출 = 한 사이클 = 한 대상 = 한 커밋.** 두 개를 욕심내지 않는다.

## 이 스킬이 있는 이유

엔진의 규칙은 전부 `engine/` 안의 문서에 있다. 이 스킬은 그 문서를 **어떤 순서로 읽고
무엇으로 시작해 무엇으로 끝내는지**만 정한다. 규칙 자체를 여기에 복사하지 않는다 —
복사본은 반드시 원본과 어긋나고, 어긋난 순간 어느 쪽이 맞는지 아무도 모르게 된다.

## 절차

### 1. 읽는다 (순서 고정)

레포 루트에서:

1. `engine/PROMPT.md` — 무엇을 쓸지. 사이클 절차의 단일 소스.
2. `engine/STYLE.md` — 어떻게 쓸지. 그림·결정·생각·논문·난제의 서술 규칙.
3. `engine/state/STATE.md` — 지난 사이클이 남긴 맥락. **엔진은 실행 사이에 기억이 없다.**
4. `engine/schema.json` — 형식. 필드를 지어내지 않는다.

### 2. 대상을 고른다

```bash
python engine/validate.py --gaps
```

출력이 사다리 순서 그대로 **이번 대상 하나**를 지목한다. 규칙의 원본은 PROMPT.md
2단계다. 요약하면: 오류 → 진행 중인 회사 확장 → 보강 후보 → QUEUE → 비교 문서.

> **`python` 을 못 찾으면** 인터프리터를 찾아 그 경로로 부른다. 검증을 건너뛰지 않는다 —
> 이 명령이 이 스킬의 유일한 입력이다. Windows 에서는 Microsoft Store 별칭 스텁(0바이트)이
> 진짜 설치를 가리는 일이 있어 `where python` 이 엉뚱한 것을 내놓을 수 있다. 실제 설치는
> 보통 `%LOCALAPPDATA%\Programs\Python\Python3xx\python.exe` 에 있다. macOS·Linux 면
> `python3` 를 쓴다. 한글 출력이 깨지면 `PYTHONIOENCODING=utf-8` 을 붙인다.

**`--gaps` 를 건너뛰고 감으로 고르지 않는다.** 루프는 매번 같은 기준으로 골라야 진도가
나간다. 사람이 기억으로 고르면 쉬운 것만 반복하게 된다.

### 3. 판다

- **확장**(새 기능) — PROMPT.md 4단계. 다섯 층을 전부 채운다.
- **보강**(빈 칸 채우기) — PROMPT.md 2′단계. **이미 쓴 것을 다시 쓰지 않는다.**
  비어 있던 칸을 채우고 틀린 칸만 고친다. `key`·`slug`·`name` 은 건드리지 않는다.
- 자료가 이전 사이클과 어긋나면 PROMPT.md 2″단계 — 조용히 덮어쓰지 말고 무엇이
  어떻게 달랐는지 `open_questions` 에 남긴다.

조사에는 WebSearch·WebFetch 를 쓴다. **못 찾은 것은 비워 둔다.** 그럴듯하게 채운
한 문장이 이 데이터 전체를 못 믿게 만든다.

### 4. 검증한다 — 실패하면 커밋하지 않는다

```bash
python engine/validate.py
```

오류(✗)가 하나라도 있으면 고칠 때까지 커밋하지 않는다. 깨진 채로 커밋하면 다음
사이클이 그것부터 고치느라 한 바퀴를 통째로 쓴다.

### 5. STATE.md 를 갱신한다

다음 실행이 이어받을 것은 이 파일뿐이다.

- `## 지금 파는 중` — **덮어쓴다.** 이어붙이지 않는다.
- `## 배운 것` — 다음 사이클이 알아야 할 것만. 사이클 기록을 쌓는 곳이 아니다.
- `## 재시도 안 함` — 두 번 찾아 두 번 다 없었던 것. 새 단서 전엔 다시 꺼내지 않는다.

### 6. 커밋한다

```
feat(reveng): <회사> <기능>        # 확장
fix(reveng): <회사> <무엇을 고쳤나>  # 보수
docs(reveng): 비교 문서 <slug>      # 비교 문서
```

데이터와 엔진 문서만. **코드 변경은 섞지 않는다.**

> `git push` 는 하지 않는다. 사용자가 명시적으로 "푸시해"라고 할 때만 한다 (CLAUDE.md).

## 아무것도 하지 않아야 하는 때

`--gaps` 가 비었고 QUEUE 도 비었으면 **없는 일을 만들지 않는다.** 그 사실만 STATE.md 에
적고 끝낸다. 채울 게 없을 때 지어내는 것이 이 데이터를 망치는 가장 빠른 길이다.

## 루프로 돌 때

`/loop <간격> /reveng` 로 반복 실행된다. 매 실행은 앞 실행의 기억이 없으므로 위 절차를
매번 처음부터 밟는다. 사이클 중간에 끊겨도 STATE.md 와 커밋 이력만 보면 다음 실행이
이어받을 수 있어야 한다 — 그것이 "한 사이클 = 한 커밋" 규칙의 이유다.
